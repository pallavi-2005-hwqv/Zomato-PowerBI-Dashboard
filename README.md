🍽️ **Data-Driven Analysis of Food Pricing, Popularity, and Customer Preferences Using Zomato Data**

📊 **Project Overview**
*Developed an interactive Zomato Food Analytics Dashboard using Microsoft Power BI to analyze restaurant pricing, ratings, cuisines, customer engagement, and city-wise performance.
The dashboard transforms Zomato data into interactive visualizations and key performance indicators to help understand restaurant and food-related trends.*

🛠️ **Tools & Technologies**
*Microsoft Power BI
Power Query
DAX
Kaggle Dataset*

📈 **Key Features**
*Restaurant pricing analysis
Restaurant rating analysis
Cuisine analysis
Number of Best Seller items
City-wise restaurant count
Highly rated food items
Restaurant and menu-item counts
Average price and average rating analysis
Interactive filters and visualizations*

🧮 **DAX & Data Analysis**
Built dynamic DAX measures and calculated columns to evaluate:
*Average Price
Overall Average Rating
Restaurant Count
Menu-Item Count
Restaurant per city*

🎯 **Project Objective**
*The objective of this project is to use data visualization and business intelligence techniques to identify patterns in food pricing, restaurant popularity, customer preferences, ratings, cuisines, and city-wise performance.*
